# 中英文切换与本地化

## 界面语言

在 GMCM 中，「语言 (Language)」位于版本标题下方。没有安装 GMCM 时，可编辑模组目录的 `config.json`。

| `Language` | 显示规则 |
| --- | --- |
| `Auto` | 默认跟随游戏语言。中文游戏使用简体中文，其余语言使用英文。 |
| `zh` | 请求简体中文。游戏字体缺少汉字时显示英文。 |
| `en` | 使用英文。 |

旧配置缺少 `Language` 或填写了未知值时按 `Auto` 处理。语言切换只影响显示文案。既有配置键、枚举值、原版界面与物品文案继续按各自的配置或游戏语言处理。

兼容的 GMCM 版本在关闭语言下拉框后立即刷新该模组的页面，保留同页未保存的选项，并在页面保持打开期间持续以预览语言渲染动态悬停说明。按 GMCM 的保存按钮后，语言选择才写入配置并在其他模组界面生效。旧版 GMCM 若缺少字段事件或页面刷新所需的成员，保存后重新打开设置页即可查看新文案。游戏原生选项页在重建时读取选定语言。

## 资源与字体保护

- [i18n/default.json](../i18n/default.json) 保存默认英文，[i18n/zh.json](../i18n/zh.json) 保存简体中文。两份资源使用相同的平面键和 `{{token}}` 占位符。ModBuildConfig 自动打包项目下的 `i18n/` 文件。
- [I18n.cs](../I18n.cs) 通过 SMAPI 的 `Get(key)` / `Get(key, tokens)` 处理自动语言。指定语言按翻译键缓存 `GetInAllLocales(key)` 结果（在游戏语区变化时自动刷新）读取 `zh` 或 `default`，仅在传入非空占位符时调用 `Tokens(tokens)`，并在缺少中文词条时回退到默认英文。
- 绘制前同时检查 `Game1.smallFont` 和 `Game1.dialogueFont`。字符集按 SpriteFont 实例缓存，游戏换用字体时重新读取。字体尚未准备好时，只接受可打印 ASCII 和换行。
- 当前字体不含探测字 `中` 时，中文请求回退为英文。检测到已加载的字体无法显示中文时，SMAPI 日志在本次运行中最多记录一次提示。
- PlayStation 的 `× / ○ / □ / △` 作为一整组检查字形：只要其中任意一个符号缺失，全部四个符号统一依次尝试对应的中文按键文字和英文按键名，避免符号与文字混排。其他缺失字形先尝试英文词条，再以可用的 `?` 替换，或省略该字符。占位符格式化后的内容也参与检查。

## 覆盖范围与验证

- **GMCM** 的版本标题、语言选项、分组、选项名、悬浮说明、下拉显示值、键位对照及模组列表简介。晶球菜单说明应为按一次 A 放上并敲开选中的晶球。
- **游戏选项页**的「始终显示工具命中位置」「移动时隐藏工具命中位置」和「缩放比例」。参见[游戏主菜单与选项](game-menus-and-options.md)。
- **背包与商店**的丢弃区标签、出售页单件与整叠价格气泡。参见[背包、箱子与出货箱](inventory-chests-and-shipping.md)及[商店交易](shops-and-animal-menu.md)。

静态验证读取两份 UTF-8 JSON，核对键无重复、值非空、同键占位符一致，并确认代码引用的键均存在。实机可依次使用中文游戏的 `Auto`、`en`、`zh` 以及英文游戏的 `zh`，分别查看 GMCM、选项页、背包及出售气泡。用 PlayStation 布局查看两种字体下的按键标识。切换语言前修改另一个设置，确认刷新后仍保留该设置，并分别检查保存及取消的结果。
